Uma nova forma de jogar Terraria.

O PROJETO

Feito para o Xbox 360 RGH

O objetivo é oferecer uma experiência nativa no console, sem depender de um navegador para gerenciar a biblioteca de mods.

▣

Gerenciador em XEX

Aplicativo nativo para abrir no Aurora, navegar pelo catálogo e administrar os pacotes instalados.

⌁

Comunidade

Um espaço público para descobrir projetos, consultar detalhes e enviar mods para análise.

⬡

Pacotes .tmod

Formato de pacote documentado com manifesto e verificação SHA-256. A primeira especificação limita o conteúdo a assets.

FLUXO PLANEJADO

Do criador ao console

O site é a porta de entrada da comunidade. O aplicativo Xbox será desenvolvido e validado separadamente.

01 · Criar

O criador prepara um pacote .tmod seguindo a especificação publicada no repositório.

02 · Enviar

O mod é submetido à comunidade para revisão. Publicações passam por aprovação antes de entrar no catálogo.

03 · Instalar

Quando o cliente XEX e o sistema de distribuição estiverem implementados, o console poderá acessar os mods aprovados.

Estado real do desenvolvimento: o site e a estrutura inicial de validação de pacotes estão sendo preparados. O gerenciador XEX ainda não está disponível; não existe uma versão compilada confirmada para testar no console. O Terraria também precisa estar instalado no console antes dos testes de integração.
