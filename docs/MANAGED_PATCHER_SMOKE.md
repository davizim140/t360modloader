# Managed IL writer smoke test

Status: PASS on GitHub Actions; this validates the editing library only.

## Test

- Library: Mono.Cecil 0.11.6.
- Runner: .NET 10 on GitHub Actions.
- Input: a synthetic fixture assembly generated by the test itself.
- Operations: create IL with a conditional branch and a catch exception region, write it, reopen it, validate branch targets and exception boundaries, write a round-trip copy, reopen and validate again.

## Result

Workflow: https://github.com/davizim140/t360modloader/actions/runs/43736086391

Artifact: `managed-patcher-smoke` (contains only the synthetic fixture and round-trip copy).

## Scope limits

- This does not prove that the Terraria Xbox 360 assembly can be safely rewritten.
- The test does not open or modify `Terraria.Managed.dll`.
- No Terraria DLL, XEX, or install package was produced.
- The next gate is a read-only Mono.Cecil inventory of the extracted Terraria assembly, followed by a separate-copy round-trip experiment only if metadata and references remain intact.
