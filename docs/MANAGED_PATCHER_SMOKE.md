# Managed IL writer smoke test

Status: PASS on GitHub Actions; this validates the editing library only.

## Synthetic writer test

- Library: Mono.Cecil 0.11.6.
- Runner: .NET 10 on GitHub Actions.
- Input: a synthetic fixture assembly generated by the test itself.
- Operations: create IL with a conditional branch and a catch exception region, write it, reopen it, validate branch targets and exception boundaries, write a round-trip copy, reopen and validate again.

Workflow: https://github.com/davizim140/t360modloader/actions/runs/43736086391

Artifact: `managed-patcher-smoke` (contains only the synthetic fixture and round-trip copy).

## Next gate: read-only Terraria inventory

A separate Mono.Cecil inventory tool is being added to inspect the extracted `Terraria.Managed.dll` without resolving XNA/XDK references and without writing the input. It records assembly identity, module metadata, type/method counts, assembly references, and branch/exception-region integrity for every method body.

## Scope limits

- The synthetic test does not prove that the Terraria Xbox 360 assembly can be safely rewritten.
- The synthetic test does not open or modify `Terraria.Managed.dll`.
- No Terraria DLL, XEX, or install package was produced.
- A separate-copy round-trip of the real assembly is not authorized until the read-only inventory is clean and the round-trip can be independently validated.
